# Config 模块 PRD

## 模块目标

定义 OpenOctopus 的统一配置协议，保证 YAML、环境变量和 flags 能稳定合并，并在启动前完成严格校验。

## 核心职责

- 基于 `Koanf` 合并配置文件、环境变量和命令行参数。
- 基于结构体与 `validator` 做字段约束、引用完整性和默认值注入。
- 输出全局可消费的强类型 `RuntimeConfig`，供 CLI、调度和执行器使用。

## 关键输入输出

- 输入：`octopus.yaml`、环境变量、命令行参数。
- 输出：已校验配置对象、校验错误列表、默认值生效记录。

## 首版边界

- 首版只支持本地文件配置与环境变量覆盖，不引入远程配置中心。
- 所有校验失败必须在 `validate` 或 `run` 前阻断，不允许带病启动。
