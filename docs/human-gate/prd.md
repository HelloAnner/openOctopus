# Human Gate 模块 PRD

## 模块目标

在自动执行链路中提供可靠的人类接管点，支持审批、驳回、打断、注入补充信息和 reroute。

## 核心职责

- 定义 WAITING_HUMAN、INTERRUPTED 等状态进入与退出规则。
- 管理审批结果、补充约束输入、人工修正与阶段重编排指令。
- 将人工操作以事件和审计文件形式落盘，供 orchestrator 与 recovery 使用。

## 关键输入输出

- 输入：人工审批命令、补充文档、打断原因、reroute 目标。
- 输出：审批记录、注入记录、状态变化事件与后续调度决策输入。

## 首版边界

- 首版以 CLI / Web 简单交互为主，不做复杂多人协同审批流。
- 所有人工介入都必须保留完整证据链，不能只留内存态结果。
