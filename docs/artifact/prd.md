# Artifact 模块 PRD

## 模块目标

统一管理工作流产物的落盘、版本演进、差异对比和血缘追踪，让每次输出都可被审计与复用。

## 核心职责

- 管理 `artifacts/{session_id}` 下的版本文件、索引文件与 manifest。
- 负责同名产物版本递增、diff 生成、hash 指纹与引用关系维护。
- 为报告、回放、审查和跨阶段输入提供稳定的产物定位能力。

## 关键输入输出

- 输入：角色输出文件、阶段结果、产物元数据、历史版本引用。
- 输出：版本化产物、索引、diff、lineage 与对外可引用的 artifact id。

## 首版边界

- 首版优先支持 Markdown、文本和代码目录产物，不做复杂二进制对象管理。
- 产物模块负责存储与索引，不负责内容生成本身。
