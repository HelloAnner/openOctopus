# CLI 模块 PRD

## 模块目标

为用户提供统一、稳定、可脚本化的命令行入口，承载工作流启动、状态观察、人工介入与报告导出等能力。

## 核心职责

- 基于 `Cobra` 暴露 `init/run/status/resume/stop/validate/report/debug` 等命令。
- 负责参数解析、帮助信息、退出码约定和标准输出格式。
- 在长时交互场景下接入 `Bubble Tea`，如 `status --watch`、审批确认和调试视图。

## 关键输入输出

- 输入：配置路径、需求文件、session id、角色 id、人工审批指令。
- 输出：命令执行结果、结构化终端反馈、标准退出码和对应用服务的调用。

## 首版边界

- CLI 只做装配和展示，不承载编排、恢复、事件总线等核心业务逻辑。
- 首版优先保证脚本友好与可观测性，复杂交互仅覆盖必要场景。
