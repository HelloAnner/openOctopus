# Extension 模块 PRD

## 模块目标

为 OpenOctopus 提供可插拔扩展能力，包括插件钩子、模板体系和未来的自定义执行器接入点。

## 核心职责

- 定义工作流生命周期钩子、插件装载方式和模板目录规范。
- 支持通知、指标、存储、自定义执行器等扩展类型。
- 保证扩展能力不破坏主流程文件协议和调度边界。

## 关键输入输出

- 输入：插件配置、模板文件、生命周期事件、扩展注册信息。
- 输出：扩展执行结果、模板初始化内容与插件副作用记录。

## 首版边界

- 首版只开放有限且明确的扩展点，不追求全量插件生态。
- 所有扩展都必须运行在受控边界内，不能绕过核心状态与安全策略。
