# Orchestrator 模块 PRD

## 模块目标

作为主 Agent 的编排核心，负责任务拆分、阶段流转、结果聚合、回路控制和终态判定。

## 核心职责

- 根据配置和需求构建阶段图、任务树与角色路由表。
- 驱动 `requirements -> implementation -> test -> review` 等流转规则。
- 执行 loop guard、重试策略、质量门禁和人工 gate 判定。

## 关键输入输出

- 输入：配置对象、事件总线结果、角色结论、产物索引、人工审批结果。
- 输出：任务分发指令、调度决策、主流程终态与重试/回流计划。

## 首版边界

- 首版采用自研 coordinator + 显式状态机，不引入重量级 Agent 编排框架。
- orchestrator 只做编排收口，不承接具体角色执行实现。
