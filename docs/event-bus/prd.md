# Event Bus 模块 PRD

## 模块目标

建立事件先落盘、状态后推进的总线协议，保证多角色协作过程有完整证据链，并支持恢复与审计。

## 核心职责

- 管理 `events.md`、`offsets.md`、`lock.md`、`interrupts.md`、`heartbeat.md` 等协议文件。
- 统一定义事件类型、追加写格式、锁租约与消费位点更新规则。
- 为 orchestrator、role-runtime、recovery 提供稳定的事件读写接口。

## 关键输入输出

- 输入：阶段开始/结束、角色执行、工具调用、人工打断、恢复重放事件。
- 输出：追加写事件日志、锁状态、心跳状态、消费进度与冲突检测结果。

## 首版边界

- 首版只允许通过事件总线驱动关键状态变更，禁止模块直接绕过总线改写核心状态。
- 事件格式以 Markdown 为主，不引入消息队列或外部事件流系统。
