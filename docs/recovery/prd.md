# Recovery 模块 PRD

## 模块目标

在崩溃、中断、超时、写冲突等异常情况下，基于事件和 checkpoint 重建系统状态并恢复执行。

## 核心职责

- 按 `events.md -> checkpoints -> master_schedule` 的顺序重建运行态。
- 校验覆盖写文件完整性、锁租约有效性与事件哈希一致性。
- 决定异常场景下的 retry / pause / abort / reroute 策略落地。

## 关键输入输出

- 输入：事件日志、checkpoint、任务看板、锁状态、恢复策略配置。
- 输出：恢复后的状态对象、恢复报告、失败原因与后续动作决策。

## 首版边界

- 首版只支持单 session 内恢复，不处理跨主机分布式恢复。
- 恢复模块只负责状态重建与恢复动作，不负责重新设计业务流程。
